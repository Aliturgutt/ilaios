# ILAIOS

ILAIOS is the canonical Enterprise AI Operating System repository.

## Canonical authority

Repository changes must follow the authority hierarchy defined in `GOVERNANCE.md`. The canonical implementation authorities are intentionally singular and discoverable from the repository root:

1. `ILAIOS_Master_Implementation_Specification_v1_0_CANONICAL_FINAL.docx` — canonical implementation specification.
2. `ILAIOS_Canonical_Milestone_Manifest_v1_0.docx` — canonical milestone manifest.
3. `GOVERNANCE.md` — repository change discipline and authority hierarchy.
4. `SECURITY.md` — repository security policy.
5. Current code, tests, CI and governed release evidence — implementation-state evidence; these cannot silently redefine higher authority.

No legacy Hermes, ILAKOS or ILATEN document is an active ILAIOS orchestration authority unless the canonical specification explicitly adopts it. Legacy names may appear only as provenance.

## Current status

See `PROJECT_STATUS.md` and `docs/governance/CAPABILITY_MATRIX.md` for evidence-based implementation state. A documented capability is not considered production merely because documentation exists.
