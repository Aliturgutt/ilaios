# License Decision

Status: CONTROLLED
Decision: PRIVATE / PROPRIETARY BY DEFAULT

## Current repository posture
The ILAIOS repository is private. No open-source license is granted by the absence of a `LICENSE` file. Copyright and other rights remain with their respective owner(s) unless a separate written agreement states otherwise.

## Rule
Do not add an OSI/open-source license, public-source grant, contributor license agreement, or third-party redistribution permission merely for tooling convenience. A licensing change is a legal/product decision requiring explicit owner approval and a dedicated governed change.

## Dependencies
Third-party dependencies remain subject to their own licenses. Dependency adoption must review compatibility with the intended proprietary distribution model and any attribution/source-disclosure obligations.

## Future decision
If ILAIOS is intentionally open-sourced or dual-licensed, record scope (whole repo vs components), selected license, copyright owner, contributor model, dependency compatibility review, and effective commit/date before adding the actual license text.

This document records repository governance intent and is not legal advice.
