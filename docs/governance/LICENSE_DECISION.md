# License Decision

Status: CONTROLLED
Decision: PRIVATE / PROPRIETARY BY DEFAULT
Repository visibility: PUBLIC

## Current repository posture
The ILAIOS GitHub repository is publicly visible. The `PRIVATE / PROPRIETARY BY DEFAULT` decision describes the licensing/reuse grant posture, not repository visibility. Public visibility does not by itself grant an open-source license or permission to copy, modify, redistribute, sublicense, or commercially reuse the repository contents. No repository-wide OSI/open-source license grant is currently recorded in GitHub repository metadata or by a root `LICENSE` file. Copyright and other rights remain with their respective owner(s) unless a separate written agreement states otherwise.

This file records the intended licensing posture; it is not a substitute for release-specific third-party notices, dependency-license reconciliation, provider/model terms, generated-output rights review, or legal advice.

## Rule
Do not add an OSI/open-source license, public-source reuse grant, contributor license agreement, or third-party redistribution permission merely for tooling convenience. A licensing change is a legal/product decision requiring explicit owner approval and a dedicated governed change.

Do not describe the repository as private while it is publicly visible, and do not describe public visibility as an open-source grant.

## Dependencies
Third-party dependencies remain subject to their own licenses. Dependency adoption must review compatibility with the intended proprietary distribution model and any attribution/source-disclosure obligations.

Before commercial distribution, produce release-specific dependency/SBOM and attribution evidence for the exact release artifact and reconcile any required notices or source-disclosure obligations.

## Future decision
If ILAIOS is intentionally open-sourced, source-available under an explicit reuse license, or dual-licensed, record scope (whole repo vs components), selected license, copyright owner, contributor model, dependency compatibility review, redistribution terms and effective commit/date before adding the actual license text.

This document records repository governance intent and is not legal advice.
