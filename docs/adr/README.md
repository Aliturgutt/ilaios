# ILAIOS — Architecture Decision Records (ADR)

**Status:** Canonical Rationale Companion
**Primary Architecture Authority:** `../SYSTEM_ARCHITECTURE.md`

This directory records the rationale behind significant ILAIOS architecture decisions.

ADR records are **rationale**, not a competing architecture authority. If an ADR conflicts with a canonical architecture, security, data, API, governance, testing, deployment, FinOps, observability, or recovery document, the applicable canonical document controls and the ADR must be updated or superseded.

## Rule

A new ADR is required only for a material architecture decision or a deliberate change to a previously accepted decision. ADR creation alone does not prove implementation, testing, deployment, or production readiness.
