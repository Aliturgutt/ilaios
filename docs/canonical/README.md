# ILAIOS Canonical Documentation

ILAIOS is the single master brand and extensible platform. ILATEN and Hermes identify historical architecture and implementation provenance only.

Authority is separated by concern:

1. `ILAIOS_Master_Implementation_Specification_v1_0_CANONICAL_FINAL.docx` governs implementation and promotion order.
2. `ILAIOS_Canonical_Milestone_Manifest_v1_0.docx` operationalizes that order for bounded execution.
3. `ILAIOS_ENTERPRISE_AI_OPERATING_SYSTEM_CANONICAL_ARCHITECTURE.md` governs product architecture and engineering requirements without claiming they are implemented.
4. Repository code, tests, validation output, and durable evidence determine actual implementation state.

The legacy ILATEN source remains migration provenance, not a parallel active authority.
