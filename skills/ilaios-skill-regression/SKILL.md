# ilaios-skill-regression

Identity: `ilaios.skill.engineering.regression.v1`, IMPLEMENTED.

Purpose: compare candidate evaluation evidence with the approved baseline and block promotion on material quality regression.

## Rules

- Use compatible scenario/evaluation evidence; do not compare unrelated runs as proof.
- Negative regression beyond the configured threshold blocks promotion before policy/approval or runtime provisioning.
- Security/governance regressions are blocking even when aggregate quality improves.
- Never waive a regression because a candidate is newer, cheaper or faster.
