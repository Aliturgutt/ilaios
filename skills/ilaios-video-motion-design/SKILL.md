# ILAIOS Video Motion Design

Use this skill to translate storyboard intent into explicit composition elements and timeline-aware motion instructions.

## Canonical execution

Reuse the existing M19 composition boundary. Prefer deterministic, parameterized motion instructions over opaque editor state. Motion may include titles, animated text, lower thirds, overlays, transitions, charts, progress indicators, dynamic captions, zoom/pan, parallax-style movement, and reusable visual templates when the active renderer supports them.

## Boundaries

A composition instruction existing is not evidence that the deployed renderer applies it. Final render and visual QA must verify actual pixels.
