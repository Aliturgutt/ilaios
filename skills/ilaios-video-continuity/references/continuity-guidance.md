# Continuity guidance

Continuity is state propagation, not repeated adjectives.

- Every beat starts from the result of the previous beat.
- Preserve object counts and ownership after transfers.
- Track open/closed/attached/removed states for manipulated objects.
- Preserve travel direction and screen direction unless a deliberate axis change is described.
- Occlusion must not become an identity reset; state what must reappear unchanged.
- For cuts, re-establish only the invariants needed to prevent drift.
- Define the final settled state so continuation work has an exact next-state anchor.
