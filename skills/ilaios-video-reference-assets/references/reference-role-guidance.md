# Reference-role guidance

Assign references by semantic responsibility rather than by provider slot count.

Typical roles:

- image: identity, product geometry/material, wardrobe, environment/layout, opening frame, ending frame;
- video: performance, choreography, camera path, mechanism timing, editing rhythm;
- audio: voice identity/delivery, dialogue timing, music rhythm, ambience.

A reference should not silently control unrelated properties. If an image controls product geometry, exclude its background/camera/lighting unless those properties are intentionally part of the request.

Provider-specific maximum counts are not encoded here. The canonical provider capability/transport layer owns those limits and must fail closed when an adapter cannot prove support.
