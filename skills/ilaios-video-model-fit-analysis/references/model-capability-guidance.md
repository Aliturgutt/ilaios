# Model capability fit guidance

Model-fit analysis should be driven by declared M04 capabilities, not brand preference, and must never become canonical routing authority.

Useful capability dimensions include:

- text-to-video,
- image-to-video,
- reference-to-video,
- first/last-frame conditioning,
- edit,
- extend/continue,
- native audio,
- multi-shot composition,
- timed-sequence control.

Current model families may expose different combinations of these features, but that information is replaceable data. ILAIOS updates capability profiles independently of the skill implementation. This skill only analyzes fit among caller-admitted profiles; it does not become a provider registry, routing policy, provider selector, or commercial authority.
