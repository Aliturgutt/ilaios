# Security Rules

1. Declare authentication, authorization, tenant and trust boundaries.
2. Keep secrets in scoped secret/key systems, not ordinary application data.
3. Treat external inputs, tool outputs and provider responses as untrusted until
   validated.
4. Apply least privilege to service identities and data access.
5. High-risk implementation actions remain subject to ILAIOS policy and approval.
6. System-design analysis is not an execution grant and cannot authorize bypasses.
