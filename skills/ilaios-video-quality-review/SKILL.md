# ILAIOS Video Quality Review

Use this skill only on an exact rendered artifact.

## Canonical execution

Reuse `GovernedVideoQualityPipeline`. Require technical validation plus independent VISUAL, AUDIO and BRAND observations bound to the same artifact SHA-256.

Review pacing, asset relevance, caption readability/sync, transition coherence, chart/diagram readability, narration intelligibility, music/SFX balance, brand consistency, and technical integrity.

## Boundaries

A generated file is not accepted because rendering returned success. Acceptance remains evidence-backed and fail-closed.
