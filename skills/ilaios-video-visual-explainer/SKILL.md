# ILAIOS Video Visual Explainer

Use this skill when narration benefits from an explanatory visual instead of stock footage.

## Canonical execution

Represent the explanation as deterministic composition data: chart series, comparison rows, timeline events, callouts, labels, map/diagram assets, and scene timing. Reuse the canonical composition/timeline path and existing diagram capability where appropriate.

## Boundaries

Do not fabricate data. Every factual value shown on screen must come from admitted evidence. Rendering support and readability must be verified on the exact output artifact.
