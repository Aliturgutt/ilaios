# Directing guidance

ILAIOS Video Director favors observable production direction over adjective stacks.

- Establish the opening state before describing action.
- Use cause -> contact -> resulting motion -> reaction -> settling state for physical interactions.
- Use a single motivated camera concept per beat; if the camera changes because of an event, name the trigger and stopping point.
- Keep one lighting logic and one visual treatment unless a deliberate transition is required.
- Treat audio as part of the action timeline: dialogue, ambience, effects, music, or intentional silence.
- Reserve the final beat for the intended ending composition and residual motion.
- For multi-shot work, every cut must add new spatial, state, time, or viewpoint information; otherwise prefer a continuous camera move.
