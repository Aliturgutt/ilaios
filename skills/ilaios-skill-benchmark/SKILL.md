# ilaios-skill-benchmark

Identity: `ilaios.skill.engineering.benchmark.v1`, IMPLEMENTED.

Purpose: compare the same immutable skill candidate across repeated runs or multiple eligible models/providers without changing governance authority.

- Bind every result to candidate digest, model/provider identity, scenario set and evidence.
- Report pass rate, assertion rate and available cost/token/latency measurements without inventing missing telemetry.
- Cross-model results are comparative evidence, not provider approval.
- Provider selection remains under canonical routing and policy controls.
