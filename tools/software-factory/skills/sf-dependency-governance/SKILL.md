# sf-dependency-governance

Identity: `sf-dependency-governance` v1.0.0, IMPLEMENTED, supply-chain-commercial, critical risk.

Purpose: govern manifest/lockfile dependency changes. Inputs: `intent`, `dependency_changes`. Outputs: package/version/source/direct-or-transitive role/reason/integrity/security/license/commercial compatibility and policy disposition.

Disposition is ALLOW, REVIEW_REQUIRED, or BLOCK. No unexplained dependency addition and no silent restrictive/unresolved license introduction. Independent review is required.

The common `../CONTRACT.md` applies.
