## External reference boundary

The public `DeusData/codebase-memory-mcp` repository was inspected only to understand the code-intelligence problem space and public capability categories. No source code, test code, documentation passages, schemas, persistence formats, binary artifacts, or implementation-specific code were copied into ILAIOS.

The ILAIOS implementation was designed against the pre-existing first-party `src/code_intelligence` repository snapshot/analyzer contracts and the governed Software Factory repository-intelligence port.

## Independently implemented concepts

ILAIOS independently implements its own:

- immutable graph schema;
- deterministic graph identifiers and generation fingerprint;
- conservative static call-resolution algorithm;
- bounded query engine;
- typed symbol/dependency/architecture/route operations;
- advisory dead-code candidate policy;
- semantic-versus-structural coverage model;
- revision-bound Software Factory adapter;
- tests and JSON schemas.

## Excluded from v1

Persistent graph databases, external embeddings, generic graph query languages, cross-repository shared state, and automatic code deletion are intentionally excluded pending dedicated governance and architecture decisions.
