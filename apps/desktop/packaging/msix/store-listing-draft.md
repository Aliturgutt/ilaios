## Short description

Windows desktop client for securely viewing and interacting with verified ILAIOS control-plane state.

## Description

ILAIOS Desktop is the Windows client for the ILAIOS control plane. It presents authenticated operational state, live execution information, evidence metadata, and governance surfaces while keeping authorization, policy, tenant isolation, scheduling, execution, and critical decisions in the authoritative backend/control plane.

The Desktop application is designed as a secure projection client rather than a standalone system authority. It does not fabricate unavailable capabilities, expose control-plane secret references, or move governed execution decisions into the client.

## Verified feature candidates

- Authenticated ILAIOS control-plane projection.
- Live operational and execution-state views.
- Evidence and audit metadata surfaces.
- Backend-authoritative governance approval interactions when an independent approver identity is configured.
- Windows-first Flutter desktop experience.
